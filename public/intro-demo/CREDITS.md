# Источники иллюстративных фотографий (прототип /intro)

Все изображения в этой папке — иллюстративные снимки для демонстрационных
проектов «NOVE TECH CONFERENCE» и «NOVE TEAM DAY». Это вымышленные проекты:
фотографии не представляют реальных клиентов или проведённых внедрений.

Получены через Openverse API (Flickr, свободные лицензии CC BY / CC BY-SA /
CC0), обрезаны и сжаты (WebP) для использования в прототипе.
